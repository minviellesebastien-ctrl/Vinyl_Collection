# Collection Vinyles — PWA

PWA personnelle prête pour GitHub Pages.

## Fichiers principaux
- `fond.png` : fond de l'application
- `ajout.png` : bouton d'ajout
- `index.html` : interface
- `style.css` : thème noir, blanc, gris et jaune
- `app.js` : liste, animation et ajout local
- `manifest.webmanifest` et `service-worker.js` : installation et fonctionnement hors connexion

## Mise en ligne sur GitHub Pages
1. Créez un dépôt GitHub.
2. Déposez tous les fichiers **à la racine** du dépôt.
3. Ouvrez **Settings > Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez la branche `main` et le dossier `/ (root)`, puis enregistrez.

Les vinyles ajoutés sont enregistrés localement sur l'appareil avec `localStorage`.
